# GPay Banking Ops

Small Angular operations UI for the Banking API health endpoint.

## Development

```bash
npm install
npm start
```

The development API URL defaults to `http://localhost:63340` and can be changed in `src/environments/environment.ts`.

## Build and deploy

```bash
npm run build
```

The production build is written to `dist/gpay-banking-ops/browser`. See [IIS deployment](IIS.md) for hosting requirements.
